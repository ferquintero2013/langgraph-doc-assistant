# sdk/upload

> Fuente: https://docs.auco.ai/sdk/upload

## 📄️ Carga de documentos con anexos
La funcionalidad de Carga de Documentos con Anexos permite la integración de documentos principales junto con archivos adicionales que actúan como anexos dentro del mismo flujo de firma, así como solicitar documentos adjuntos sin necesidad de un documento principal.

## 📄️ Carga de documentos para firma
La funcionalidad de Carga de Documentos para Firma permite integrar, a través del SDK, la subida segura de documentos que deben ser firmados electrónicamente.
