# sdk/intro

> Fuente: https://docs.auco.ai/sdk/intro

Bienvenido a la documentación de la Integración de los SDK de Auco . Cada SDK es un iframe , y se comunica por medio del API de PostMessage .
En este espacio podrás conocer como integrar los siguientes SDKs en tu aplicación.
Subir documentos para firmar
Solicitud de anexos
Firma electrónica de documentos
Firma de paquetes
Aprobación de documentos
Lectura de documentos
Llenado de plantillas

## Prerequisitos ​
Antes de integrar cualquiera de los SDKs, es necesario cumplir con los siguientes requisitos.
Cuenta en Auco
Llaves de integración
Dependiendo del ambiente que se desee utilizar cambiarán las llaves de integración, para ver la información de los ambientes puedes leer la documentación de Entornos y Autenticación.

## Libreria necesaria ​
Para facilitar la integración de SDKs se desarrolló la auco-sdk-integration con la cual se hace la integración de todos los SDK, es necesario instalar esta librería por medio de NPM:
`auco-sdk-integration`
`$ npm install auco-sdk-integration`
