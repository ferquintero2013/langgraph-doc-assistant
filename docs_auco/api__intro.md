# api/intro

> Fuente: https://docs.auco.ai/api/intro

Bienvenido a la documentación oficial del API de Auco.
Aquí encontrarás todo lo necesario para integrar los servicios de gestión documental digital que ofrecemos. Nuestro objetivo es facilitar a organizaciones externas la implementación eficiente y segura de procesos como firma electrónica, envío de documentos, validación de identidad y más.

## Características del API ​
Basado en REST
Respuestas en formato JSON
Autenticación mediante API Key
Endpoints organizados por servicio (documentos, firmas, validación, etc.)
🔗 Accede al entorno de pruebas (stage) desde stage.auco.ai

## ¿Cómo comenzar con el API de Auco? ​
Para empezar a usar nuestra API, sigue estos pasos:
Crea una cuenta en el entorno de producción y en el entorno de pruebas (stage).
Adquiere una bolsa de créditos contactando a un asesor comercial o directamente desde el portal en producción.
Configura el perfil de tu organización desde tu cuenta.
Realiza pruebas en el entorno stage .
Pasa a producción cuando estés listo. A partir de ese momento, se contabilizan los documentos procesados y se activa la facturación correspondiente.
