# api/manager/attachments

> Fuente: https://docs.auco.ai/api/manager/attachments

## 📄️ Crear proceso de anexos
Este servicio permite iniciar un proceso para solicitar anexos para firma o simplemente anexos sin firma. Cada anexo puede configurarse como obligatorio u opcional.

## 📄️ Consultar anexos
Este servicio permite consultar los anexos cargados por los firmantes dentro de un proceso. El comportamiento de la respuesta varía según se incluya o no el parámetro userId.
