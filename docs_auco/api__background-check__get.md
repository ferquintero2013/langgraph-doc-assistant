# api/background-check/get

> Fuente: https://docs.auco.ai/api/background-check/get

Servicio para realizar la consulta de una validación de antecedentes.

## Autenticación ​
Incluye tu llave publica en el encabezado Authorization .
`Authorization`
`Authorization : puk_xxx...`

## Parámetros de consulta ​
PARAMETROS: Nombre | Descripción ;; code String | Obligatorio. Código del proceso a consultar.
