# api/manager/package

> Fuente: https://docs.auco.ai/api/manager/package

## 📄️ Crear paquete
Este servicio permite generar paquete de documentos a partir de una plantilla de Auco o de un archivo PDF. Al terminar el proceso, obtendras cada documento con su propio certificado de firma.

## 📄️ Consultar paquetes
Este servicio permite consultar paquetes de documentos en Auco.

## 📄️ Recordatorio del paquete
Con este servicio puedes enviar recordatorios de firma y/o aprobación a los participantes de tu paquete documental de forma manual, esta es una alternativa a los recordatorios automáticos que defines al momento de la creación.
